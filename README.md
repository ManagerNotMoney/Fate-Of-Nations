# 🏛️ FreePoliticsSandbox

Политическая веб-стратегия в разработке.

## 📁 Структура проекта

```
game-strategy/
├── index.html          # Главная страница (меню + игра)
├── css/
│   └── style.css       # Стили (тёмная тема, анимации)
└── js/
    └── main.js         # Логика меню, переходы, частицы
```

## 🚀 Как запустить

Просто откройте `index.html` в браузере. Никакого сервера не требуется!

## 🎮 Функционал

### Главное меню
- ✅ Красивое тёмное оформление с анимированными частицами
- ✅ Выбор размера карты (Маленькая / Средняя / Большая)
- ✅ Выбор количества игроков (2 / 4 / 6)
- ✅ Выбор сложности (Новичок / Стандарт / Эксперт)
- ✅ Кнопка "Начать игру"
- ✅ Кнопка "Авторы" с модальным окном
- ✅ Кнопка "Как играть" (заглушка)

### Экран игры
- ✅ Заглушка "В РАЗРАБОТКЕ" с анимированным прогресс-баром
- ✅ Кнопка возврата в меню

### Модальное окно авторов
- ✅ ManagerMoney (Менеджер Денег) — Создатель и Геймдизайнер
- ✅ Kimi 2.6 — ИИ-ассистент разработки
- ✅ W.Solutions.Games — Игровое подразделение
